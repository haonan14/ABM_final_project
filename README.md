# The Pivot Penalty as Emergent Structure

Agent-based model of the pivot penalty in science, built with [Mesa](https://mesa.readthedocs.io/).

MACSS 40550 *Agent-Based Modeling* Final Project — Simmons Yin

## Files

- `model.py` — Model definition
- `agents.py` — Scientist agent
- `app.py` — Interactive dashboard (`solara run app.py`)
- `batch_run.py` — Batch analysis and figure generation
- `paper.tex` — Paper source
- `figures/` — All figures (generated by `batch_run.py`)

## Setup

```bash
pip install -r requirements.txt
solara run app.py          # interactive GUI
python batch_run.py        # regenerate figures
```
